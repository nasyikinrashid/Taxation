CAPTAIN’S HANDBOOK

Every file has a destination.

  1. Read the cargo file and its tax facts.
  2. Click or tap an answer dock, or steer with ← / → (A / D). Keys 1–4 also select a dock.
  3. Choose Dispatch cargo or press Enter to send the file.
  4. Read the feedback. Choose Continue after a correct answer or Continue to retry after a mistake.
  5. Deliver all files to open the lighthouse. Use Previous to review earlier files, then Next to return.

Learning score: 1 point for a correct first attempt without the Rule card. A first attempt using the Rule card is recorded as assisted. Retries complete the voyage but do not restore first-attempt points.

No speed points. Untimed is the default. The optional stopwatch only records active answering time. It never ends the game and pauses during feedback, review and instructions.

All cases use YA 2025 and Malaysian sources. Unless stated otherwise, the person is a Malaysian tax-resident individual. The final file is a new application case.

Audio: gentle background music, a departure chime, cargo dispatch notes, a bright correct-answer chime, a soft retry cue and a completion melody. Music becomes quieter during feedback. Use the audio bar to mute, switch off music, or change the volume. It pauses when the page is hidden.
